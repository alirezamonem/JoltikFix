# JoltikFix
Text Formatter Tool

JoltikFix is a sleek, minimalist web-based text utility designed for speed and efficiency. It empowers users to quickly manipulate, format, and generate placeholder text with ease, all within a modern, GNOME-inspired glassmorphism interface.

---

## 🚀 Features

- **Advanced Text Manipulation:** Effortlessly transform text with options like Uppercase, Lowercase, Capitalize, and Smart Sentence Case.
    
- **Smart Formatting:** Quickly remove excess whitespace, clean line breaks, and normalize your text structure.
    
- **Built-in Lorem Ipsum Generator:** Generate custom placeholder text (English/Persian) with variable lengths and types.
    
- **Modern UI/UX:** A distraction-free environment featuring a beautiful, responsive Dark Mode design based on GNOME Adwaita principles.
    
- **Instant Stats:** Real-time character and word count tracking.
    
- **Clipboard Integration:** Seamless one-click copy, paste, and clear functionality.
    

## 🛠 Tech Stack

- **Vanilla JavaScript:** Fast, lightweight, and dependency-free performance.
    
- **HTML5 & Modern CSS3:** Leveraging CSS Variables for a robust, modular design.
    
- **Responsive Design:** Optimized for seamless performance on both desktops and mobile devices.
    

## 💻 How to Use

JoltikFix is a single-file application. No installation is required!

1. Open `index.html` in any modern web browser.
    
2. Type or paste your text into the main editor.
    
3. Select a transformation tool from the toolbar to instantly modify your content.
    
4. Use the Lorem Ipsum section to generate dummy text on the fly.
    
5. Click "Copy" to save your edited text to the clipboard.
